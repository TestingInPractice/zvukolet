# Приватность: Звуколёт

Дата: 2026-11-14
Задача: Vikunja #261
Статус: черновик для ревью перед публикацией

## Коротко для родителя

Приложение работает офлайн. Оно не собирает данные, не требует аккаунта и не
отправляет ничего в сеть. Прогресс и настройки хранятся только на устройстве.

## Какие данные обрабатываются

- Результаты занятий: попытки и ошибки по парам и режимам.
- Настройки: громкость звука, включение звука.
- Пользовательские наборы: созданные родителем наборы пар и их медиа.

Все эти данные остаются на устройстве в локальном хранилище приложения
(`user://`). Они не передаются в сеть и не покидают устройство.

## Чего приложение не делает

- Не требует регистрации, email или пароля.
- Не запрашивает доступ к камере и микрофону.
- Не записывает голос ребёнка.
- Не использует распознавание речи.
- Не собирает аналитику и не отправляет события.
- Не показывает рекламу.
- Не использует сторонние трекеры.

## Сетевые запросы

В MVP приложение не делает сетевых запросов. Продуктовое обещание: приложение
работает без интернета. Проверка офлайн-режима выполняется в задаче Vikunja
#257.

## Удаление данных

Родитель может удалить все данные через `Настройки` -> `Сбросить прогресс`.
Удаление пользовательских наборов выполняется в конструкторе. Удаление
приложения удаляет все локальные данные.

## Дети и приватность

Приложение предназначено для домашней практики ребёнка 3-6 лет вместе со
взрослым. Приложение не собирает персональные данные ребёнка и не создаёт
профиль. Оценка результата остаётся за взрослым.
