# Карточка RuStore: Звуколёт

Дата: 2026-11-14
Задача: Vikunja #262
Статус: черновик для публикации

## 1. Название

Звуколёт

## 2. Короткое описание (до 80 знаков)

Короткие занятия на различение похожих звуков. Офлайн.

## 3. Полное описание

Звуколёт помогает родителю провести короткое занятие (3-5 минут) дома с
ребёнком 3-6 лет. Ребёнок учится различать похожие слова на слух и в речи, а
взрослый помогает и отмечает результат.

Первый набор это контраст `ш-с`. Есть три режима: послушай и выбери, повтори за
взрослым, назови картинку.

Приложение работает офлайн. Оно не требует регистрации, не собирает данные, не
показывает рекламу и не использует подписку. Прогресс хранится только на
устройстве.

Приложение не ставит диагноз, не заменяет логопеда и не обещает постановку
звука. Оценка результата остаётся за взрослым. Задания рекомендует логопед.

## 4. Ключевые слова

логопед, логопедия, речь, звуки, шипящие, свистящие, минимальные пары,
различение звуков, дети, офлайн, без рекламы

## 5. Категория

Образование / Для детей (уточнить актуальную категорию в RuStore).

1. Стартовый экран с объяснением.
2. Выбор режима.

5. Экран итога занятия.
6. Родительский экран с прогрессом.

## 7. Честность описания

- Не обещать лечение, диагноз и постановку звука.
- Не показывать клинические проценты.
- Не сравнивать с другими детьми.
- Писать, что это домашняя практика по заданию логопеда.
