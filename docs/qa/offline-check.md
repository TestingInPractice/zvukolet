# QA: офлайн-режим и отсутствие сетевых запросов

Дата: 2026-11-14
Задача: Vikunja #257
Сборка: Godot 4.6.3.stable, headless, `--path .`

## Что проверяли

Что приложение не делает сетевых запросов и работает без интернета, как
обещает позиционирование.

## Метод

1. Статический поиск по исходникам: искали сетевые API Godot и URL.
2. Автотест `_run_offline_tests` в `tests/test_runner.gd`: рекурсивно читает
   `res://scripts/*.gd` и `res://scenes/*.tscn` и падает, если находит сетевой
   токен.
3. Запуск без окна: приложение поднимается без обращений к сети.

## Искомые токены

`HTTPClient`, `HTTPRequest`, `WebSocketPeer`, `StreamPeerTCP`, `PacketPeerUDP`,
`TCPServer`, `UDPServer`, `StreamPeerTLS`, `WebSocketClient`, `WebSocketServer`,
`connect_to_host`, `http://`, `https://`.

## Наблюдения

- Поиск по `scripts/`: совпадений нет. Единственные вхождения слова `request` это
  сигналы интерфейса `close_requested` и метод `request_reset`, к сети отношения
  не имеют.
- Автотест: `в исходниках нет сетевых вызовов`. Итог `=== проверок: 103,
  ошибок: 0 ===`, выход 0.
- Запуск без окна: выход 0, ошибок скриптов нет.

## Почему этого достаточно

В MVP нет ни одного сетевого вызова: ни HTTP, ни сокетов, ни мультиплеера.
Приложение читает только локальные ресурсы (`res://`) и пишет только в
локальное хранилище (`user://`). Без сетевых вызовов приложение работает без
интернета по построению. Автотест фиксирует это в CI и не даст добавить сетевой
вызов незаметно.

## Что не покрыто

- Подтверждение на устройстве с включённым авиарежимом: входит в #256.
- Мониторинг трафика устройства: не требуется, так как сетевых вызовов нет.
