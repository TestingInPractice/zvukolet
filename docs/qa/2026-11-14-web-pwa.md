# QA: web-сборка и PWA

Дата: 2026-11-14
Задача: web-экспорт Godot + PWA (план `docs/plans/pwa-web-export-plan.md`)
Сборка: Godot 4.6.3.stable, шаблон `web_nothreads_release.zip`, Playwright (Chromium)

## Что проверяли

Что проект экспортируется в Web как офлайн-PWA: страница грузится, приложение
стартует, манифест корректен, service worker регистрируется, в консоли нет
ошибок, и что сборка работает без cross-origin isolation (GitHub Pages не отдаёт
заголовки COOP/COEP).

## Команды

```bash
godot --headless --path . --import
godot --headless --path . --export-release "Web" build/web/index.html
cd build/web && python3 -m http.server 8123
```

Затем Playwright (Chromium headless) открывает `http://localhost:8123/index.html`.

## Наблюдения

- Экспорт: `EXPORT_EXIT=0`, `[ DONE ] savepack`.
- Файлы в `build/web`: `index.html`, `index.js`, `index.wasm` (37.7 МБ),
  `index.pck`, `index.manifest.json`, `index.service.worker.js`,
  `index.audio.worklet.js`, `index.audio.position.worklet.js`,
  `index.offline.html`, иконки `index.144x144.png`, `index.180x180.png`,
  `index.512x512.png`, `index.apple-touch-icon.png`, `index.icon.png`.
- Манифест: `name` `Звуколёт`, `display` `standalone`, `orientation` `portrait`,
  `background_color` `#f5f0e8`, иконки 144/180/512, `start_url` `./index.html`.
- head_include: в `index.html` есть `apple-mobile-web-app-capable`, `theme-color`,
  скрипт `__godotAudioCtx` и `viewport-fit=cover`.
- Playwright: заголовок `Звуколёт`, canvas 540x1170, service worker
  `http://localhost:8123/index.service.worker.js` активен,
  `crossOriginIsolated=false`, ошибок в консоли нет, ошибок страницы нет.
- Рендер: скриншот 540x1170, 620 уникальных цветов, доминирует фон `#F5F0E8`,
  присутствуют кнопки `#3D8B7D`. Это реальный экран, а не пустой canvas.
- Единственные сообщения: предупреждения WebGL о производительности в headless
  (GPU stall), к приложению не относятся.

## Почему этого достаточно

Проверено главное для PWA: приложение собирается, стартует в браузере без
cross-origin isolation, отдаёт корректный манифест и регистрирует service worker
(основа офлайна). Отсутствие ошибок в консоли и рендер UI подтверждают, что
сборка рабочая.

## Что не покрыто

- Установка PWA на домашний экран и офлайн-перезагрузка после первого визита:
  проверяется на хостинге (HTTPS) после деплоя.
- Проверка на iOS Safari и на реальном мобильном устройстве.
- Аудио в браузере стартует по жесту пользователя: скрипт возобновления
  `AudioContext` добавлен, поведение на реальном устройстве проверяется вручную.

## Изоляция и секреты

- Тестовая страница обслуживается локальным `http.server`; реальные `user://` не
  трогаются.
- Секретов в артефактах нет.
