# QA-план и чеклист MVP: Звуколёт

Дата: 2026-11-14
Задача: Vikunja #255
Область: MVP `ш-с`, три режима, локальный прогресс, Android.

## 1. Цель QA

Доказать, что MVP работает на реальном Android-устройстве, в офлайне, без
блокеров, и что занятие проходится от начала до конца. QA в MVP ручное, на
устройстве. Автотесты покрывают только чистые функции.

## 2. Область проверки

- Запуск и навигация по экранам.
- Три режима: `послушай и выбери`, `повтори за взрослым`, `назови картинку`.
- Аудио: образец слова, интерфейсные звуки, громкость.
- Прогресс и настройки: сохранение между запусками, сброс с подтверждением.
- Офлайн: работа без интернета, отсутствие сетевых запросов.
- Конструктор: создание набора, экспорт и импорт `.zvset`.
- Экран `О проекте`: версия, дисклеймер, приватность.

## 3. Что не входит

- Автоматическая оценка речи (в MVP нет ASR).
- Клинические выводы и проценты.
- iOS.
- Производительность на слабых устройствах за пределами тестового телефона.

## 4. Автотесты (headless)

Запуск:

```bash
godot --headless --path . --import
godot --headless --path . tests/test_runner.tscn
```

Ожидание: `=== проверок: N, ошибок: 0 ===`, выход 0. Автотесты проверяют
контент, хранилище наборов, формат `.zvset`, навигацию, аудио, SFX, сохранение,
сессию, режимы, прогресс, родительский экран, настройки и экран `О проекте`.

## 5. Сборка APK

```bash
godot --headless --path . --import
godot --headless --path . --export-debug "Android" builds/android/zvukolet.apk
adb install -r builds/android/zvukolet.apk
```

Ожидание: APK собирается, устанавливается на чистое устройство, приложение
запускается.

## 6. Чеклист на устройстве

Запуск и навигация:

- [ ] Приложение запускается без интернета.
- [ ] Стартовый экран показывает название, пояснение и три кнопки.
- [ ] `Начать` открывает выбор режима.
- [ ] `Назад` возвращает на предыдущий экран.
- [ ] `Конструктор наборов` открывает список наборов.
- [ ] `Родителям` открывает прогресс.

Режим `послушай и выбери`:

- [ ] Слово звучит чётко.
- [ ] Показаны две картинки.
- [ ] Верный выбор даёт мягкую обратную связь.
- [ ] Неверный выбор не наказывает и предлагает попробовать снова.
- [ ] `Повторить звук` повторяет образец.

Режим `повтори за взрослым`:

- [ ] Показаны картинка и слово.
- [ ] Звучит образец.
- [ ] Взрослый может отметить `Получилось` или `Повторим`.

Режим `назови картинку`:

- [ ] Показана картинка без подписи.
- [ ] Взрослый может отметить `Верно` или `Повторим`.

Сессия:

- [ ] Сессия проходится от начала до конца.
- [ ] Счётчик попыток растёт.
- [ ] Кнопка `Закончить` завершает сессию.
- [ ] Экран итога показывает попытки и верные ответы.
- [ ] Звук завершения играет в конце.

Прогресс и настройки:

- [ ] Прогресс сохраняется после закрытия и повторного запуска.
- [ ] Родительский экран показывает пары, ошибки и последнее занятие.
- [ ] `Сбросить прогресс` требует подтверждения.
- [ ] Подтверждённый сброс очищает прогресс.
- [ ] Громкость сохраняется между запусками.
- [ ] Звук можно выключить и включить обратно.

Офлайн:

- [ ] С включённым авиарежимом приложение работает как обычно.
- [ ] Приложение не показывает ошибок сети.
- [ ] Приложение не делает сетевых запросов (проверка #257).

Конструктор:

- [ ] Набор создаётся и переименовывается.
- [ ] Пары включаются и исключаются.
- [ ] Набор экспортируется в `.zvset`.
- [ ] Набор импортируется обратно.
- [ ] Импортированный набор играется в режимах.

Экран `О проекте`:

- [ ] Показана версия приложения.
- [ ] Показан дисклеймер.
- [ ] Показан текст приватности.

## 7. Критерии прохождения

- Автотесты: 0 ошибок.
- Все пункты чеклиста отмечены или имеют явную запись о дефекте.
- Нет блокеров: приложение запускается, занятие проходится, прогресс
  сохраняется, офлайн работает.
- QA evidence собран в `docs/qa/` (задача #258).

## 8. Формат дефекта

Для каждого дефекта: заголовок, шаги, ожидаемое, фактическое, серьёзность
(блокер, крупный, мелкий), устройство и версия Android, скриншот или лог без
секретов и без голоса ребёнка.

## 9. Ограничения

- Не прикладывать голос ребёнка и личные данные.
- Не прикладывать секреты, токены и keystore.
- Проверять на реальном устройстве: эмулятор не заменяет проверку звука и
  производительности.
