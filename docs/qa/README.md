## Как читать

Каждый файл это одна проверка: что проверяли, команды, наблюдения, почему
достаточно, что не покрыто, артефакты. Секреты, голос ребёнка и личные данные в
evidence не попадают.

## Автотесты

- Раннер: `tests/test_runner.tscn`, 103 проверки.
- Запуск: `godot --headless --path . --import` затем
  `godot --headless --path . tests/test_runner.tscn`.
- Ожидание: `=== проверок: 103, ошибок: 0 ===`, выход 0.
