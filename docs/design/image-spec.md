# Спека иллюстраций MVP

Дата: 2026-11-16
Задача: #242.

## Назначение

Иллюстрация называет предмет пары без подписи: ребёнок видит картинку и
слышит слово. Рисунок детский, плоский, векторный, на прозрачном фоне,
чтобы карточка одинаково смотрелась на любом экране.

## Формат и размеры

- Формат: PNG, RGBA, прозрачный фон.
- Размер: 512 на 512.
- Один предмет по центру, без фона, рамки и текста.
- Палитра спокойная, без неоновых и тревожных цветов.
- Стиль: плоский детский клипарт, мягкие скруглённые формы, чистые контуры.

## Связка с контентом

- Пути заданы в `content/pairs/sh_s.json` в полях `image_a` и `image_b`.
- Формат пути: `res://assets/images/pairs/sh_s/<pair_id>_<side>.png`.
- Имя файла: `<pair_id>` это id пары (`sh_s_NN`), `<side>` это `a` или `b`.
- Загрузка: `SetRepository.load_texture` (в веб-сборке через `Image.load`, без `.import`).
- Подстановка по слову: `ContentRepository.find_media_by_word`.
- Конструктор: `scripts/ui/set_editor.gd`, своя картинка вытесняет встроенную.

## Генерация

Картинки сгенерированы FLUX2 через A1111-совместимый API на втором ПК
(`http://192.168.0.224:8080/sdapi/v1/txt2img`), фон срезан на iloveimg.com,
контроль среза выполнен через Pillow. Точный процесс и промпты: скилл
`azbuka-images`.

Пайплайн:

1. Генерация: сплошной голубой фон, один предмет, фиксированный seed на объект.
2. Срез фона: iloveimg.com, результат с альфа-каналом.
3. Контроль: прозрачно не меньше 75 процентов, bbox по центру, кайма голубоватая.
4. Экспорт: 512 на 512, RGBA.

Исходники лежат в `docs/design/sources/sh-s/`:

- `<pair_id>_<side>_raw.png` - результат генерации, 768 на 768, RGB, голубой фон;
- `<pair_id>_<side>_cut768.png` - после среза фона, 768 на 768, RGBA.
