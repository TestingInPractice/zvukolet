# SFX-спека MVP

Дата: 2026-11-14
Задача: #244.

## Назначение

Короткие интерфейсные звуки помогают ребёнку понять результат без чтения текста.
Все звуки короткие (меньше секунды), тихие и мягкие, без резких атак.

## Список звуков

| Файл | Событие | Длительность | Характер |
| --- | --- | --- | --- |
| `assets/audio/sfx/click.wav` | нажатие кнопки | 0.08 с | короткий высокий блик |
| `assets/audio/sfx/correct.wav` | верный ответ | 0.35 с | восходящие два тона |
| `assets/audio/sfx/error.wav` | ошибка | 0.22 с | мягкий низкий тон |
| `assets/audio/sfx/complete.wav` | конец занятия | 0.55 с | три восходящих тона |

## Баланс

- Громкость канала SFX по умолчанию 0.6, ниже голоса и мастер-канала.
- Голос не перебивается: SFX играют на отдельных плеерах.
- Ошибка звучит мягко, не пугает: без резких высоких пиков.

## Код

- Пути и помощники: `scripts/core/sfx_library.gd` (`SfxLibrary`).
- Воспроизведение: `AudioManager.play_sfx`, остановка всех звуков
  `AudioManager.stop_sfx`.
- Кнопки: `ScreenStyle.wire_click` подключает звук клика к нажатию.
- Верный ответ и ошибка: `ModeBase._on_answer`.
- Конец занятия: `ModeBase._on_finish`.

## Генерация заглушек

    python3 tools/generate_stub_sfx.py

Заглушки моно, 44100 Гц, 16 бит. Финальные звуки подбираются отдельно.
