# UI-тема MVP

Дата: 2026-11-14
Задача: #243.

## Принципы

- Крупные кнопки, один понятный акцент на экран.
- Спокойные цвета без клинических и тревожных сигналов.
- Текст читается на телефоне с расстояния вытянутой руки.
- Никаких мелких интерактивных элементов.

## Палитра

| Роль | Цвет | Применение |
| --- | --- | --- |
| Фон | `#F5F0E8` | Фон всех экранов (default clear color) |
| Поверхность | `#FFFFFF` | Панели |
| Основной | `#3D8B7D` | Кнопки в покое |
| Основной наведение | `#4AA091` | Кнопки при наведении |
| Основной нажатие | `#2F6E63` | Кнопки при нажатии |
| Выключено | `#B8C4C0` | Недоступные кнопки |
| Текст | `#3A3A3A` | Подписи |
| Текст на кнопке | `#FFFFFF` | Текст кнопок |
| Фокус | `#E0A458` | Обводка фокуса |

## Размеры

- Минимальная высота кнопки: 96.
- Скругление кнопки: 20.
- Скругление панели: 24.
- Внутренние отступы кнопки: 28 по бокам, 20 сверху и снизу.
- Отступы экрана: 24 по каждой стороне.
- Отступ между элементами: 20-24.

## Состояния кнопок

- Покой: основной цвет.
- Наведение: светлее основного.
- Нажатие: темнее основного.
- Выключено: серо-зелёный.
- Фокус: обводка цветом фокуса, 4 пикселя.

## Иконки

- `assets/ui/icons/mode_listen_choose.svg`: звук и волны, режим `послушай и выбери`.
- `assets/ui/icons/mode_repeat_after_adult.svg`: круговые стрелки, режим `повтори за взрослым`.
- `assets/ui/icons/mode_name_picture.svg`: облачко с картинкой, режим `назови картинку`.
- `assets/ui/icons/back_arrow.svg`: стрелка назад, кнопки возврата.

Иконки монохромные, цвет `#3D8B7D`, размер 96 на 96.

## Файлы

- Тема: `assets/ui/theme.tres`, подключается в `project.godot` как `gui/theme/custom`.
- Сборка темы: `tools/build_ui_theme.gd`, запуск `godot --headless --path . --script tools/build_ui_theme.gd`.
- Помощники размеров и иконок: `scripts/ui/screen_style.gd`.
